# 🎨 คู่มือส่วนหน้าเว็บ (Frontend Documentation)

> วิธีติดตั้งและรันทั้งระบบ ดูที่ README.md ในโฟลเดอร์ด้านนอก

โฟลเดอร์นี้ประกอบด้วยไฟล์ส่วนติดต่อผู้ใช้งาน (User Interface) ทั้งหมดที่ถูกเขียนขึ้นแบบ **Vanilla (ไม่ใช้ Framework)** เพื่อให้แก้ไขง่าย โหลดเร็ว และนำไปส่งเป็นโปรเจกต์อาจารย์ได้ง่ายครับ โค้ดทั้งหมดถูกคอมเมนต์อธิบายการทำงานไว้แล้ว

## 📂 คำอธิบายไฟล์ในโฟลเดอร์นี้

### 1. `index.html` (หน้าเข้าสู่ระบบ)
*   **ใช้ทำอะไร:** เป็นหน้าแรกสุดเมื่อเปิดเว็บขึ้นมา (Login Page)
*   **การทำงาน:** มีช่องกรอกอีเมลและรหัสผ่าน เมื่อกดเข้าสู่ระบบจะยิง `POST /api/login` ไปที่ Backend (server.py -> auth.py)
    *   *หากไม่มี Backend รันอยู่:* จะขึ้นข้อความสีแดงเตือนว่าเชื่อมต่อไม่ได้
    *   *หากผ่าน:* เก็บ `forge_token` และ `forge_user` ไว้ใน localStorage แล้วเด้งไปหน้า `home.html`

### 2. `register.html` (หน้าสมัครสมาชิก)
*   **ใช้ทำอะไร:** หน้าสำหรับสร้างบัญชีใหม่
*   **การทำงาน:** กรอก username / email / password แล้วยิง `POST /api/register` สมัครเสร็จจะพากลับไปหน้า Login

### 3. `home.html` (หน้าหลัก - Workspace)
*   **ใช้ทำอะไร:** หน้าหลักสำหรับสร้างและจัดการรูปภาพ AI เป็นหน้าที่ซับซ้อนที่สุด
*   **การทำงาน:** แบ่งเป็น 2 ฝั่ง ซ้าย (ตั้งค่า) ขวา (แสดงผล) โดยซ่อนหรือแสดงผลตามโหมดที่เลือก:
    *   **Text to Image (⚡):** แสดงเฉพาะ Prompt, Negative Prompt, Model (ล็อกไว้ 2 ตัว) และ Seed (ภาพล็อกที่ 1:1 จัตุรัส ไม่มี LoRA)
    *   **Image to Image (🖌️):** ต้องอัปโหลดรูปเพิ่ม และสามารถใส่ Prompt ได้
    *   **Blur (💧):** ต้องอัปโหลดรูป และแสดงหลอดปรับระดับความเบลอ (Blur Strength)
    *   **Canny (✏️):** ต้องอัปโหลดรูป และแสดงช่องกำหนดเส้นขอบ (Threshold Low/High)
    *   **Object Detection (📦):** ต้องอัปโหลดรูป และแสดงหลอดเลื่อน Score Threshold สำหรับหาวัตถุ

### 4. `gallery.html` (หน้าแกลเลอรี่)
*   **ใช้ทำอะไร:** ดูรูปภาพทั้งหมดที่เราเคยกดปุ่ม "หัวใจ 🤍" บันทึกเอาไว้
*   **การทำงาน:** ดึงรูปของผู้ใช้ที่ login อยู่จาก Backend (`GET /api/gallery`, เก็บไฟล์ใน `backend/gallery_images/` และข้อมูลใน `user.db`) คลิกรูปเพื่อดูรายละเอียด และลบได้ (`DELETE /api/gallery/<id>`)

### 5. `style.css` (ไฟล์ตกแต่งหน้าตา)
*   **ใช้ทำอะไร:** รวบรวมคำสั่ง CSS สำหรับตกแต่งเว็บให้สวยงามแบบ Premium UI
*   **การทำงาน:** มีการใช้ตัวแปร (CSS Variables) สำหรับกำหนดธีมสี และเขียน Media Queries สำหรับรองรับหน้าจอมือถือ (Responsive Design)

### 5.1 `config.js` / `object-detector-module.js`
*   `config.js` กำหนด `API_BASE` (เปิดผ่าน Nginx พอร์ต 8080 -> ใช้ path เดียวกัน, เปิดแบบอื่น -> ยิงตรงพอร์ต 5000)
*   โมดูลตรวจจับวัตถุ (`object-detector-module.js`) ย้ายไปอยู่ในโฟลเดอร์ `ai/` แล้ว `home.html` โหลดผ่าน `/api/ai/object-detector-module.js`

### 6. `script.js` (ไฟล์สมองกล)
*   **ใช้ทำอะไร:** เป็นตัวควบคุมพฤติกรรมต่างๆ บนหน้า `home.html` และเป็นตัวส่งข้อมูลข้ามไปยัง Backend (Python)
*   **ส่วนสำคัญในโค้ด:**
    *   `updateUI()`: ใช้สำหรับเช็คว่าตอนนี้อยู่โหมดไหน แล้วไปสั่งซ่อน/เปิด ช่องกรอกข้อมูลต่างๆ ให้ตรงกับโหมด
    *   `submit()`: ฟังก์ชันไฮไลท์! เมื่อผู้ใช้กดปุ่มสร้างรูป มันจะรวบรวมข้อมูลทุกอย่างในหน้าเว็บ (เช่น โหมดอะไร รูปอัปโหลดคือรูปไหน Prompt ว่ายังไง) ห่อรวมกัน (Payload) แล้วยิงไปหา Python (Backend) จากนั้นรอรับรูปกลับมาโชว์ที่หน้าเว็บ
