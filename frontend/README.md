# คู่มือระบบ Frontend (Forge AI) — ฉบับเข้าใจง่าย

> **Frontend คืออะไร?**  
> เปรียบเสมือน **"หน้าร้านและพนักงานรับออเดอร์"** มีหน้าที่แสดงหน้าจอให้ผู้ใช้กดใช้งาน รับคำสั่งสร้างรูป แล้วส่งไปให้ห้องครัว (Backend / AI) ทำอาหาร พอทำเสร็จก็นำรูปภาพมาเสิร์ฟบนหน้าจอ

---

## 1. ต้องติดตั้งอะไรตรงไหนบ้าง? (3 สเต็ปพร้อมใช้)

> ✨ **ข่าวดี:** ระบบนี้เป็นหน้าเว็บแท้ (HTML/JS) **ไม่ต้องติดตั้ง Node.js หรือพิมพ์คำสั่งติดตั้งโค้ดใดๆ ทั้งสิ้น!**

### สเต็ปที่ 1: เตรียมเว็บเซิร์ฟเวอร์ (เลือก 1 วิธี)
เนื่องจากระบบความปลอดภัยของเบราว์เซอร์ **ห้ามดับเบิ้ลคลิกไฟล์เปิดตรงๆ** ต้องเปิดผ่านเซิร์ฟเวอร์จำลอง:
* **วิธีแนะนำ (ใช้ Nginx):**  
  1. ดาวน์โหลด [Nginx for Windows](https://nginx.org/en/download.html) แตกไฟล์ไว้ในเครื่อง
  2. สั่งรัน Nginx โดยชี้มาที่ไฟล์ `frontend/nginx/nginx.conf`
* **วิธีสำหรับคนใช้ VS Code:**  
  ติดตั้งส่วนเสริมชื่อ **Live Server** แล้วกดปุ่ม *Go Live* ที่มุมขวาล่าง

### สเต็ปที่ 2: ตั้งค่าเชื่อมต่อไปหา Backend (แก้จุดเดียว)
* เปิดไฟล์: `frontend/config.js`
* ดูที่บรรทัดที่ 5 แก้ IP ให้ตรงกับเครื่องที่รัน Backend (เซิร์ฟเวอร์ AI):
  ```javascript
  const API_BASE = 'http://172.20.56.134:5000'; // ใส่ IP เครื่อง Backend
  ```
  *(ถ้าเปิดเว็บผ่าน Nginx พอร์ต 8080 ให้ใส่เป็น `''` ค่าว่างได้เลย)*

### สเต็ปที่ 3: เปิดใช้งาน
* เปิดเบราว์เซอร์ (เช่น Google Chrome) เข้าไปที่:
  `http://localhost:8080` (หรือพอร์ตของ Live Server)

## 2. หน้าเว็บแต่ละหน้า ทำหน้าที่อะไรและใช้อย่างไร?

ระบบแบ่งออกเป็น **3 หน้าหลัก** ตามลำดับการใช้งาน:

```
[1. หน้า Login] ──────> [2. หน้าสร้างภาพ AI] ──────> [3. หน้า Admin]
 (index.html)              (home.html)                 (admin.html)
 เข้าสู่ระบบ/รับบัตรผ่าน      พิมพ์สั่งสร้างภาพ/โหลดรูป       จัดการสมาชิก (เฉพาะแอดมิน)
```

### 1) หน้าเข้าสู่ระบบ (`index.html`)
* **วิธีใช้:** กรอก **อีเมล** และ **รหัสผ่าน** แล้วกดปุ่ม *"เข้าสู่ระบบ"* (ถ้ายังไม่มีบัญชีให้กดไปหน้า `register.html` เพื่อสมัคร)
* **การทำงาน:** ระบบจะส่งรหัสไปตรวจ ถ้าถูกต้อง เซิร์ฟเวอร์จะให้ **"บัตรผ่านดิจิทัล (Token)"** มาเก็บไว้ในเครื่อง แล้วพาข้ามไปหน้าหลักอัตโนมัติ

### 2) หน้าหลักสำหรับสร้างภาพ (`home.html`)
* **วิธีใช้:** 
  1. เลือกโหมด เช่น สั่งวาดจากข้อความ (*Text to Image*) หรือ แปลงจากภาพต้นฉบับ (*Image to Image*)
  2. พิมพ์คำสั่ง (Prompt) ที่ต้องการ
  3. กดปุ่ม **"สร้างภาพ"**
* **การทำงาน:** หน้าเว็บจะส่งคำสั่งไปให้ AI วาดภาพ เมื่อเสร็จแล้วรูปภาพจะเด้งขึ้นมาบนหน้าจอทันที สามารถกดไอคอน **"🤍 (หัวใจ)"** เพื่อบันทึกลงแกลเลอรี่ส่วนตัว หรือกดปุ่มดาวน์โหลดรูปได้

### 3) หน้าจัดการผู้ใช้ (`admin.html`)
* **วิธีใช้:** จะมองเห็นและเข้าใช้งานได้ **เฉพาะผู้ใช้ที่เป็นระดับ Admin เท่านั้น**
* **การทำงาน:** แสดงรายชื่อผู้ใช้งานทั้งหมดในระบบ สามารถค้นหาชื่อ แก้ไขข้อมูล หรือกดลบบัญชีผู้ใช้ทิ้งได้

## 3. เบื้องหลัง: หน้าเว็บรับและส่งข้อมูลยังไง? (สรุปแบบง่าย)

การทำงานทุกอย่างในเว็บ ทำงานเป็นรอบวงกลมง่ายๆ 3 ขั้นตอน:

1. **รับข้อมูลจากเรา:** เมื่อเราพิมพ์ข้อความ หรือเลือกไฟล์รูป หน้าเว็บจะดึงค่านั้นมารวมไว้ในก้อนข้อมูล
2. **ส่งไปหลังบ้าน:** หน้าเว็บจะแนบ "บัตรผ่าน (Token)" แล้วส่งข้อมูลผ่านคำสั่ง `fetch` ยิงไปที่ Backend
3. **รับผลลัพธ์มาแปะที่จอ:** เมื่อหลังบ้านประมวลผลเสร็จ จะส่งภาพกลับมา หน้าเว็บจะสั่งให้หน้าจอแสดงรูปใหม่ทันที โดยที่เราไม่ต้องกดรีเฟรชหน้าเว็บ

## 4. แผ่นป้ายสรุปไฟล์สำคัญ (Cheat Sheet)

| ไฟล์ | ความหมายแบบเข้าใจง่าย |
| :--- | :--- |
| **`config.js`** | จุดตั้งค่าที่อยู่ (IP) ของเครื่องแม่ข่าย |
| **`index.html`** | ประตูหน้าบ้าน ใช้ล็อกอินเข้าสู่ระบบ |
| **`home.html`** | ห้องทำงานหลัก สำหรับพิมพ์สั่ง AI ให้วาดรูป |
| **`admin.html`** | ห้องควบคุม สำหรับแอดมินจัดการสมาชิก |
| **`script.js`** | สมองกลของหน้าเว็บ คอยกดปุ่ม รับส่งข้อมูล วาดรูปขึ้นจอ |
| **`style.css`** | เสื้อผ้าหน้าผม คอยแต่งสี ปุ่ม และขนาดตัวหนังสือให้สวยงาม |
| **`nginx.conf`** | รปภ. คอยเปิดหน้าเว็บให้ผู้ใช้ และส่งต่อคำขอไปหาเซิร์ฟเวอร์ AI |
